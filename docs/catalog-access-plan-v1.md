# Remaining catalog route access proof

The preserved Gamma scout returned 403 for all seventeen API requests, while seven
documentation requests succeeded. That is an access-path observation, not catalog
absence or proof of a fundamental historical capability gap. Do not rerun that scout.

The next bounded standard-Linux Actions probe uses these documented alternatives:

- One minimal Gamma series request with an honest project User-Agent and JSON Accept.
- Initial CLOB `/markets` and `/simplified-markets` cursor pages.
- Seven `/markets-by-token/{token_id}` identity-only lookups from the pinned prior cohort.
- The official geographic diagnostic, retaining only blocked/country/region; it describes
  order-placement geography, not automatically the cause of catalog access denial.
- The public robots file and one known-cohort event-slug hypothesis. Retain advertised
  first-party sitemap URLs and strictly projected embedded identity metadata only.
- `eth_chainId` against `https://polygon-rpc.com`, the public Polygon transport referenced
  in the official Rust CTF client. This transport is not Polymarket-owned. This request
  establishes chain transport identity only; no logs, prices, trades or results are read.

All fourteen requests are fixed and bounded; no redirects, browser impersonation,
authentication challenge handling, cookies, proxies or geographic rotation are used.
Each response is under 8 MB and the total is capped at 64 MB. Bodies remain transient;
only strict identity/listing projections, selected non-sensitive headers, hashes,
counts and fixed denial classifications may enter the evidence report. HTTP/transport
errors, byte caps and unsupported shapes retain null results, never empty-catalog or
NOT_EXPECTED authority. The reusable immutable report remains evidence-only.

This probe does not enumerate an entire CLOB catalog or certify a target day. If a
metadata route works, its measured shape and cursor behavior determine the next
bounded enumeration step. On-chain preparation and question metadata can corroborate
positive identity; they cannot silently be treated as an off-chain listing schedule.
